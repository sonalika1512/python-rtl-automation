Python for RTL Engineering 🐍
Welcome to Python for RTL Engineering!

This repository documents my daily journey of learning Python, starting from the fundamentals and gradually moving towards practical automation used in RTL Design and VLSI engineering.

The goal is not just to learn Python syntax, but to understand how Python can help RTL engineers automate repetitive tasks, analyze simulation results, process files, and improve design workflows.

This repository is beginner-friendly. If you are new to Python or want to learn how Python is used in the semiconductor industry, you can follow the same learning path.

🎯 What is this repository about?
Python is a powerful programming language that can be used in semiconductor and hardware design workflows.

RTL engineers regularly work with:
- RTL source files (Verilog/SystemVerilog)
- Simulation logs and reports
- Testbenches and simulation results
- Waveform analysis
- Regression testing
- Design automation scripts
Python can help automate many repetitive activities involved in these tasks.

Through this repository, we will gradually move from basic Python programming to practical RTL design automation.

🛣️ Learning Roadmap
The learning journey is divided into different stages. Each stage builds on the concepts learned in the previous one.
Phase 1: Python Fundamentals
Learn the basic concepts required to write Python programs.

Topics:
- Introduction to Python
- Variables and Data Types
- Operators
- Conditional Statements
- Loops (for and while)
- Strings and String Operations
- Lists, Tuples, Sets and Dictionaries
- Functions
- Modules and Packages
- Exception Handling
Goal: Become comfortable writing basic Python programs independently.
Phase 2: Intermediate Python
Learn how to write structured and reusable programs.

Topics:
- File Handling
- Reading and Writing Text Files
- CSV File Handling
- JSON File Handling
- Regular Expressions
- List Comprehensions
- Functions and Modular Programming
- Object-Oriented Programming
- Working with Command-Line Arguments
- OS and Pathlib Modules
- Subprocess Module
Goal: Learn to work with files, directories, data, and external tools using Python.
Phase 3: Python for RTL Automation
Apply Python concepts to tasks commonly performed by RTL engineers.

Topics:
- Reading and Parsing Verilog Files
- Extracting Module and Port Information
- Searching RTL Files
- Working with Multiple RTL Files
- Automating Compilation Commands
- Running Simulation Using Python
- Executing Simulator Commands
- Processing Simulation Logs
- Detecting Errors and Warnings
- Generating Simulation Reports
- Automating Regression Runs
Goal: Reduce repetitive manual work through Python scripting.
Phase 4: Practical RTL Automation Projects
Build small projects using the concepts learned in previous phases.

Planned projects:
1. RTL File Analyzer
   - Read Verilog files.
   - Extract module names and port information.
   - Generate a basic RTL summary.
2. Simulation Log Analyzer
   - Read simulator log files.
   - Identify errors and warnings.
   - Extract PASS and FAIL messages.
   - Generate a summary report.
3. Simulation Automation Script
   - Execute compilation commands.
   - Run simulations.
   - Capture output logs.
   - Check simulation status.
4. FIFO Test Automation
   - Work with a FIFO RTL design.
   - Automate simulation execution.
   - Analyze simulation results.
   - Generate a test execution summary.
5. Regression Automation
   - Run multiple test cases.
   - Collect simulation results.
   - Identify failed tests.
   - Generate a regression summary.
