# 01 - Python Basics 🐍

This section covers the fundamentals of Python programming. It is designed for beginners who are starting from scratch.

The focus is on understanding basic concepts, writing small programs, and building a strong foundation before moving towards Python automation for RTL design.

## 📚 Topics Covered

1. Introduction to Python
2. Variables and Data Types
3. Input and Output
4. Operators
5. Conditional Statements (if, elif, else)
6. Loops (for and while)
7. Strings and String Operations
8. Lists, Tuples, Sets and Dictionaries
9. Functions
10. Basic Problem Solving
